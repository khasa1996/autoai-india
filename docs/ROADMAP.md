# Delivery and acceptance roadmap

Status must be based on executed checks. This document describes remaining scope, not a completion claim.

1. Foundation: isolated monorepo, local persistence, shared validation, authentication boundary, schemas and tests. Production identity, MongoDB adapter and recovery remain separate acceptance items.
2. Showroom: responsive discovery, verified catalogue ingestion, filtering and vehicle details. Complete India catalogue and licensed imagery require source agreements and editorial verification.
3. Configurator: local GLB validation, orbit/camera and material/component controls. Vehicle-specific authored assets, pivots, LOD and compatibility approval are required before production use.
4. Intelligence: tested calculators, deterministic evidence-based ranking and comparisons. A multilingual generative advisor requires an approved fresh provider and evaluation set.
5. Dealers: scoped membership, inventory offers and booking requests. Business verification must be backed by reviewed records; nationwide integration is not a code-only deliverable.
6. Transactions: safe state transitions and provider interfaces. Sandbox gateway/webhook verification, reconciliation, refunds, secure document storage, partner exchange and finance integrations remain prerequisites.
7. Fulfilment: verified milestones, idempotent notification outbox, logistics source and handover evidence. Do not display invented progress.
8. Mobile and language rollout: native platform builds and device QA; English plus 22 scheduled language registry, reviewed dictionaries and native-script QA. A registry is not complete localization.
9. Hardening: load and abuse tests, accessibility audit, backups/restores, key rotation, security assessment, legal review and production approval.

Each phase requires tests, regressions fixed, documentation, and a current feature report. No paid service, production deployment, protected-branch merge or real payment is authorized by this plan.
